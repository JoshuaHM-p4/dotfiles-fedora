Write and run tests for the feature described in your task context, against the already-implemented backend and frontend. Do not change non-test source files; if you find a bug, report it with a failing test and a short diagnosis instead of fixing it.

When done, report what you covered, the exact commands you ran, pass/fail results, and any defects found.
